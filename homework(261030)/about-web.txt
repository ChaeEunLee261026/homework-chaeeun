1. 웹의 기본 동작 원리 알아보기
(다음 용어가 무엇을 의미하는지 조사하기)

-클라이언트(Client) : (클라이언트 = 요청하는 쪽)
클라이언트란 서버에게 정보를 요청하거나 서비스를 이용하는 컴퓨터 또는 프로그램을 의미
ex) 우리가 컴퓨터에서 인터넷 검색을 하거나 웹사이트에 접속할 때 사용하는 컴퓨터와 웹 브라우저가 클라이언트 역할을함
(쉽게 말하면 필요한 것을 요청하는 손님과 같음)

-서버(Server) : (서버 = 응답하는 쪽)
서버란 클라이언트가 요청한 정보를 처리하고 결과를 제공하는 컴퓨터 또는 프로그램을 의미
eX) 네이버에서 검색하면 네이버 서버가 검색 내용을 처리하고 검색 결과를 보내줌
(쉽게 말하면 손님이 요청한 음식을 만들어 제공하는 음식점과 같음)

-IP 주소 : (IP 주소 = 네트워크 주소)
인터넷에 연결된 기기나 네트워크 인터페이스를 구분하고 통신할 때 사용하는 주소
인터넷에서 정보를 주고받을 때 데이터가 어디로 전달되어야 하는지 알려주는 역할을함
ex) 192.168.0.1
쉽게 말하면 인터넷에 연결된 기기의 주소와 같음

-포트번호 : (포트번호 = 통신할 프로그램이나 서비스 구분 번호)
컴퓨터에서 어떤 프로그램이나 서비스와 통신할지 구분하기 위해 사용하는 번호
하나의 컴퓨터에서도 여러 프로그램이 동시에 통신할 수 있기 때문에 각각의 통신 대상을 구분하는 역할을함
ex) 80번: HTTP 통신, 443번: HTTPS 통신
쉽게 말하면 건물 안에서 원하는 사무실을 찾기 위한 방 번호와 같음

-URL : (URL = 웹페이지의 주소)
인터넷에서 원하는 웹페이지나 자료가 어디에 있는지 알려주는 주소
웹 브라우저의 주소창에 입력하는 인터넷 주소가 URL
ex) https://www.naver.com
URL에는 통신 방식, 도메인 이름, 포트번호, 자료의 경로 등이 포함될 수 있음
쉽게 말하면 인터넷에서 원하는 정보를 찾기 위한 상세 주소와 같음

-웹 브라우저 : (웹 브라우저 = 웹사이트를 이용하고 보여주는 프로그램)
인터넷에 있는 웹사이트에 접속하고 웹페이지를 화면에 보여주는 프로그램
대표적인 웹 브라우저에는 Google Chrome, Microsoft Edge, Safari, Firefox 등이 있음
웹 브라우저는 클라이언트 역할을 하며 서버에 정보를 요청하고, 서버에서 전달받은 정보를 사용자가 보기 쉽게 화면에 표시함

*각 용어의 관계*
우리가 웹 브라우저에서 웹사이트 주소(URL)를 입력하면 웹 브라우저가 클라이언트 역할을 하여 서버에 정보를 요청한다.
이때 도메인 이름에 해당하는 IP 주소를 DNS를 통해 확인하고, 포트번호를 이용하여 서버의 통신 대상에 연결한다.
서버는 클라이언트가 요청한 정보를 처리한 후 결과를 전달한다.
마지막으로 웹 브라우저는 서버에서 받은 데이터를 해석하여 사용자에게 웹페이지를 보여준다.

즉, 클라이언트는 정보를 요청하고, 서버는 정보를 제공하며, IP 주소와 포트번호는 통신 대상을 찾고 구분하는 역할을 한다. 
URL은 요청할 웹페이지의 주소이고, 웹 브라우저는 이 모든 과정을 사용자가 쉽게 이용할 수 있도록 도와주는 프로그램이다.
(위 6가지는 인터넷과 웹 개발을 배울 때 가장 기본이 되는 개념!)
