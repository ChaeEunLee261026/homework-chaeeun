1. 도메인과 DNS란 무엇인가?

-도메인(Domain) : (인터넷 주소)
도메인은 인터넷에서 특정 웹사이트를 찾아가기 위한 이름
예시와 같이, 사람이 쉽게 기억하고 사용할 수 있도록 만든 인터넷 주소가 바로 도메인
ex) naver.com / google.com

-DNS(Domain Name System) : (인터넷 주소 번역기)
도메인 이름을 IP 주소로 바꿔주는 시스템

*DNS가 작동하는 과정 :
1. 사용자가 주소 입력(ex_naver.com)
2. DNS 서버가 IP 주소 검색(ex_naver.com에 해당하는 IP 주소를 찾음)
3. IP 주소로 웹사이트 서버에 접속(컴퓨터가 해당 서버를 찾아감)
4. 웹사이트 화면 표시(네이버 홈페이지 출력)
즉, 도메인 = 사람이 사용하는 인터넷 주소 
    IP 주소 = 컴퓨터가 서버를 찾는 숫자 주소
    DNS = 도메인을 IP 주소로 변환하는 시스템

2. DNS서버가 고장나면 웹사이트 접속은 어떻게 될까?
-DNS서버가 고장나면 도메인 이름으로 웹사이트를 찾는것이 어려워짐.
(캐시나 IP 주소를 이용하면 접속 가능한 경우도 있음)

*DNS서버란? 도메인에 해당하는 IP 주소를 찾아주는 서버
